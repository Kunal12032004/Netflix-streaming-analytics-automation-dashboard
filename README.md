# Netflix Streaming Analytics & Automation Dashboard

## Overview
An interactive Power BI dashboard for analyzing Netflix content, ratings, and global trends, supported by an n8n workflow that automates poster-data retrieval and storage.

## Tools & Technologies
- Power BI
- DAX and Power Query
- PostgreSQL
- n8n
- TMDB API

## Dashboard Pages
- Executive Overview
- Content Analytics
- Global Trends & Title Explorer

## Project Files
- `netflix_analytics_v2.pbix` — Power BI dashboard
- `N8n workflow.png` — n8n automation workflow
- Dashboard screenshots — visual previews of the report

## How to View
Download the `.pbix` file and open it in Power BI Desktop.
